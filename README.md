# Screenshot Utilities

F2 screenshots you can crop, copy and clean up after the shot. Hide your HUD bit by bit, keep a mob in colour, and show your
best pictures on the main menu. Minecraft 1.21.1, NeoForge, client only.

Downloads and the full description are on [CurseForge](https://www.curseforge.com/minecraft/mc-mods/screenshot-utilities).

## Features
- A popup after F2 with crop, copy to clipboard (Windows), erase and filters. The original is always kept.
- Hide HUD after the shot, all of it or one element at a time, and an Always hide list.
- A magic wand: click a mob to pick the whole mob, or anything else to pick by colour. Zoom in with the scroll wheel.
- Retake with shader: the same shot in another installed Iris shader pack, with your edits kept.
- A gallery folder, shown as a slideshow on the main menu and loading screens.
- Your pictures stay on your PC. The mod has no network code.

## Reporting issues
Bugs and ideas go in the [issues](https://github.com/DEWSTREAMING/ScreenshotUtilities/issues/new/choose) here. Add a crash
report or log link if the game crashed.

## Building
Java 21 and NeoForge 21.1.x (ModDevGradle).

```
gradlew build
```

The jar ends up in `build/libs/`. `gradlew test` runs the unit tests.
